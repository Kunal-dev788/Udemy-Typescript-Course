# 🎯 Lecture Goal

Is lecture ka goal hai apna development environment ready karna taaki hum TypeScript properly use kar sakein.

Hume install karna hai:

- ✅ Node.js  
- ✅ npm (Node Package Manager)  
- ✅ Visual Studio Code  
- ✅ Project Folder Setup  

---

# 🟢 Step 1: Install Node.js

## 🔹 Node.js Kyu Chahiye?

TypeScript ko:
- Install karne ke liye
- Compile karne ke liye
- Dependencies manage karne ke liye

⚠️ Important:
Hum Node.js code nahi likhenge.
Hum sirf TypeScript install aur run karne ke liye Node use karenge.

---

## 🌐 Kaise Install Kare?

1. Website open karo:
   https://nodejs.org

2. Download button pe click karo  
3. **LTS Version** install karo  

### 📌 LTS Kya Hota Hai?

**LTS = Long Term Support**

Matlab:
- Stable version
- Production ready
- Long term support

Installer download hone ke baad:
- Run karo
- Next → Next → Install

---

# 🟢 Step 2: Install Visual Studio Code (VS Code)

## 💻 VS Code Kyu?

- Free hai
- Microsoft ka hai
- Industry standard hai
- Lightweight aur powerful hai

Download from:
https://code.visualstudio.com

Install karo aur open karo.

---

# 🟢 Step 3: Project Folder Create Karo

1. Computer me ek new folder banao  
   Example: `TypeScript Masterclass`

2. VS Code open karo  
3. Click on **Open Folder**  
4. Apna folder select karo  

Ab workspace ready hai 🎉

---

## 📂 Folder View Shortcut

Explorer panel dekhne ke liye:

- Windows: `Ctrl + 1`
- Mac: `Cmd + 1`

---

# 🎨 Optional: Same Theme Use Karna (Material Ocean)

Agar same look chahiye:

1. Extensions open karo
2. Search karo: `Material Theme`
3. Install karo
4. Material Ocean select karo

⚠️ Ye sirf UI change karta hai.
Course ke liye mandatory nahi hai.

---

# 🟢 Step 4: Terminal Open Karna

VS Code ke andar hi terminal open karo.

Shortcut:

- Windows: `Ctrl + 2`
- Mac: `Cmd + 2`

Ya:
Terminal → New Terminal

---

# 🟢 Step 5: Check Node.js Installed Hai Ya Nahi

Terminal me ye command likho:

```bash
node --version
```

Agar version number aa gaya 🎉  
Matlab Node.js successfully install ho gaya.

Example output:

```bash
v21.6.2
```

---

# 🟢 Step 6: Check npm Installed Hai Ya Nahi

npm automatically Node ke saath install hota hai.

Check karne ke liye:

```bash
npm --version
```

Agar version show ho raha hai ✅  
Matlab npm bhi correctly install ho gaya.

---

# 📦 npm Kya Hai?

**npm = Node Package Manager**

Use hota hai:
- Packages install karne ke liye
- TypeScript install karne ke liye
- Dependencies manage karne ke liye
